## 📝 How It Works

### On Page Load
1. Inline script detects current time (21:40)
2. Since 21:40 is between 6 PM - 6 AM → **Dark mode loads**
3. Background: Navy (#0f172a)
4. Text: Light gray (#f1f5f9)
5. No toggle button visible

### Time Display
1. JavaScript `TimeUpdater` class runs on page load
2. Gets current time (21:40)
3. Updates `#phone-time` element to "21:40"
4. Updates every 60 seconds automatically
5. Displays with white background box

### Theme Persistence
1. When you refresh the page, it remembers your preference
2. Auto-detection runs only on first visit
3. Your choice is saved in localStorage
